# NordWerk

A one-page portfolio concept for a fictional German interior-fit-out firm. The site presents renovation, drywall, flooring, and painting as a coordinated Handwerk offering — not a live business.

**Live Demo:** [https://nordwerk-website.vercel.app](https://nordwerk-website.vercel.app)

## Technologies

HTML5, CSS3, Vanilla JavaScript

## Features

- Responsive layout for desktop and mobile
- Mobile navigation
- Semantic HTML
- Demo contact form (no backend; submissions stay in the browser)

## Project Purpose

A self-contained front-end piece for a portfolio: German-language copy, a commercial Handwerk look, and a static stack with no frameworks.

## Disclaimer

NordWerk is fictional. Addresses, phone numbers, testimonials, and other contact details are invented for this demonstration and do not belong to a real company.
